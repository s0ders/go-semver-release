# Install

### GitHub Releases

The preferred method of installation is via the releases generated by the CI workflow of the official GitHub repository:

```bash
$ VERSION=v8.0.3
$ curl -fsSLO https://github.com/s0ders/go-semver-release/releases/download/${VERSION}/go-semver-release-linux-amd64
$ curl -fsSLO https://github.com/s0ders/go-semver-release/releases/download/${VERSION}/go-semver-release-linux-amd64.intoto.jsonl
```

Releases are available for various OS and architectures and come with generated [provenance](https://slsa.dev/spec/v1.0/provenance) of SLSA level 3 to avoid being tampered with, ensuring a strong layer of protection against supply chain attacks.

Verify the provenance with [slsa-verifier](https://github.com/slsa-framework/slsa-verifier) before running the binary, especially in CI where it is given an access token:

```bash
$ slsa-verifier verify-artifact go-semver-release-linux-amd64 \
    --provenance-path go-semver-release-linux-amd64.intoto.jsonl \
    --source-uri github.com/s0ders/go-semver-release \
    --source-branch main
$ chmod +x go-semver-release-linux-amd64
```

In GitHub Actions, `slsa-verifier` can be installed with the [`slsa-framework/slsa-verifier/actions/installer`](https://github.com/slsa-framework/slsa-verifier#installation) action, see the [workflow examples](../recipes/workflow-examples.md).

### Go

If [Go](https://go.dev) is installed on your machine, the project can be installed from its source code:

```bash
$ go install github.com/s0ders/go-semver-release/v8@latest
$ go-semver-release --help
```

### Docker

A [Docker image](https://hub.docker.com/r/s0ders/go-semver-release/tags) is available as well:

```bash
$ docker pull s0ders/go-semver-release:v8.0.3
$ docker run --rm s0ders/go-semver-release:v8.0.3 --help
```

Images are only published with their version tag: pin one (ideally by digest, e.g., `s0ders/go-semver-release@sha256:...`) rather than relying on `latest`. Each image comes with build provenance and SBOM attestations, which can be inspected with `docker buildx imagetools inspect s0ders/go-semver-release:<VERSION> --format '{{ json .Provenance }}'`.
